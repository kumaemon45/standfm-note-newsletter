# 利用者設定

このファイルは1人または1組織ごとに分け、必要な項目だけ入力してください。メールのパスワード、認証コード、APIキー、Cookieやトークンは保存しないでください。サービスへのログインは本人が各画面で行います。

## 利用先

- 設定の識別名：未設定
- stand.fm チャンネルURL（使う場合）：未設定
- note プロフィールURLまたはアカウントID：未設定
- 原稿の受け渡し：チャット / Googleドキュメント / 毎回選ぶ（未設定）
- Googleドキュメントで使うアカウントの識別名（任意）：未設定
- Gmail 差出人アドレス（使う場合）：未設定
- メルマガ配信先リストの場所またはサービス名（使う場合）：未設定
- Threads プロフィールURLまたはユーザーネーム（使う場合）：未設定
- タイムゾーン：未設定

## 希望する使い方

- 記事本文：本人が書く / 本人がAIに依頼して作る（未設定）
- 本文中の見出し直下の画像：枚数を確認して自動生成・挿入 / 不要 / 希望する配置（未設定）
- Threadsの文章とnoteリンク：毎回決める / 希望する方法（未設定）
- メルマガの配信先・配信日時：毎回確認 / 希望する方法（未設定）
- 原稿・音声・作業記録の保存場所と保持期間：未設定

この設定はアカウントを識別するための記録です。ログイン・接続権限の有効性や投稿・送信への承認を意味しません。
